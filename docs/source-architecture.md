# 音源架构

项目只维护当前网络协议和配置格式，不提供旧版接口或配置别名。部署端、启动器与前端必须使用同一版本。房间存档尝试备份并导入，再改写为当前格式，不提供旧协议运行模式；部署前仍应自行备份数据。

## 身份边界

- 部署配置决定启用的音源与 `DIRECT_URL` / `SERVER_DOWNLOAD` 交付方式；功能能力由适配器代码声明。
- 配置 Cookie 用于受限音频，以及明确允许的私人 FM/DJ 原生推荐。不作为个人收藏目标，不承担成员账号授权。
- 用户收藏通过搜索并选择用户完成本机绑定，接口只查询客户端明确传入的公开目标 UID，不携带目标用户 Cookie，不回退配置账号。不提供直接输入 UID 的界面；未提供用户搜索能力的源不能在当前界面首次绑定。
- 房间密码、绑定目标和 LIKESONG 在前端本机保存。LIKESONG 不属于后端收藏类别，禁用源不会删除或过滤本机记录。

## 模块与配置

`SourceRegistry` 注册适配器，校验唯一 sourceId、能力目录及交付模式。启停只有 `sources` 映射一个权威入口，适配器连接参数中没有第二份启用状态。

```yaml
app:
  music-api:
    sources:
      netease:
        enabled: true
        delivery-mode: DIRECT_URL
      bilibili:
        enabled: true
        delivery-mode: SERVER_DOWNLOAD
    private-dj:
      source: netease
```

环境变量为 `NETEASE_ENABLED`、`BILIBILI_ENABLED`、`NETEASE_DELIVERY_MODE`、`BILIBILI_DELIVERY_MODE` 和 `PRIVATE_DJ_SOURCE`。连接地址、Cookie、音质保留在对应适配器技术配置中。管理台可修改启停；交付模式与推荐源由部署决定，不从运行时存档覆盖。未知音源或不支持的交付类型明确失败，不换源。

`SourceRegistry.update` 更新授权 epoch；禁用再启用不会使旧媒体票据或旧异步任务重新有效。

## 资源与公开收藏

当前资源接口统一为 `/api/v2`：

- `/sources`：已启用源、代码能力、收藏分类及交付目录。
- `/sources/{source}/tracks/search`、`/users/search`：搜索。
- `/sources/{source}/collection-categories`、`/collections/{category}?userId=&cursor=&limit=`：显式公开目标收藏。
- `/sources/{source}/containers/{type}/{id}` 及 `/tracks`：容器详情和歌曲分页。
- `/sources/{source}/tracks/{id}/album`、`/lyrics`：歌曲所属专辑与歌词。
- `/playbacks/{playbackId}/media`、`/media/refresh`：当前播放实例的媒体获取与恢复。

房间初始化后需通过房间访问检查；参数、能力与上游失败使用结构化错误，不伪造成功空数据。公开页面装饰配置不包含音源凭据。

分页为 `ResourcePage {items,nextCursor,total}`，只有 `nextCursor=null` 表示结束。过滤失效内容后允许空页加下一游标；前端提供显式加载下一页，短页和没有滚动条也能继续读取。游标绑定音源、目标、类别或容器、页大小与目录版本，不能串用。

收藏类别区分 TRACK 与 CONTAINER。TRACK 直接返回歌曲；CONTAINER 返回容器。适配器明确接收容器类型与 ID，同源不同类型可以使用相同 ID。当前网易云提供公开歌单，B站提供公开收藏夹；不提供配置 Cookie 账号的收藏专辑类别，公开专辑详情与所属专辑能力独立保留。

容器导入元数据和所有分页共用完整预算；在用户→音源→队列固定锁序下复核成员、音源 epoch、身份及配额。异步迟到或来源不匹配的结果不提交。请求标识提供幂等性，提交后的预取失败不把成功入队伪报为失败。

## 私人 FM/DJ

部署 `private-dj.source` 指定唯一提供源，网易云使用配置 Cookie 请求原生 FM/DJ，QQ音乐使用明确的单账号 Credential 请求原生 FM（不提供 DJ 语音）。提供者声明基础 FM 和可选 DJ；后端按指定源下发 `source`、`fmSupported`、`djSupported`。前端只展示明确支持的入口，其他已启用源不能借用能力，后端也拒绝不支持的模式。

保留填空、固定 FM 入队和托管。推荐请求在调度时捕获模式与选择代次；关闭、切换模式、更新 Cookie 或启停后拒绝旧请求及迟到结果。推荐错误明确报告，不切换成公开歌单。

歌曲使用统一媒体服务；语音为 VOICE，支持该源配置的两种交付模式及 Radio，不当歌曲 ID 解析、不进普通歌曲历史或保留歌单、不走歌曲刷新。语音时长必须有效，单段不超过600秒。语音采用有界独立下载通道，同段重试复用准备身份，不跨进程恢复过期语音。

## 播放、媒体与缓存

`ResourceKey(sourceId,id)` 是队列判重、状态和缓存的内容身份；queueId 标识队列项，playbackId 标识播放实例。URL 签名不作为稳定内容身份。

元数据、解析和下载分离，网络准备在房间锁外，提交复核版本、音源和授权范围。首播账本在服务端成功起播时更新，预取不算首播。禁用音源的排队条目保持待处理；单曲循环的授权失败会释放加载状态而非卡死调度。

- DIRECT_URL 必须适合浏览器原生播放，不依赖秘密请求头。
- SERVER_DOWNLOAD 流式写入受限临时文件，验证后原子提交；浏览器使用支持 Range 的短时票据。预取与播放共享真实下载完成状态，失败时允许一次表示级降级（如 DASH → html5 MP4），仍由服务端下载并缓存，不降级浏览器直链。主表示与降级表示共用发起时的授权范围、资源身份和有效期校验；更新 Cookie 或音源代次后，旧结果不得写入新授权缓存。用户重试失败曲目时重新排入任务，不能只把失败状态改成等待。降级预取完成后，正式播放可在重新校验表示与时间轴一致时复用已下载资产，不重复等待失败的主下载；缓存关闭会终结未完成任务，不遗留无限轮询。
- 媒体分别声明编码 representation 与内容 timeline；同内容可跨编码，整曲变试听或切换时间窗口不能沿用原播放进度。
- 刷新以已签发的当前播放对象和 playbackId 为准，不修改 seekNonce、队列或共享进度。
- 缓存版本包含音源、内容、编码、timeline 与授权命名空间。播放 pin 绑定实际签发资产，不随未接受的刷新候选移动。
- 进程授权 session 隔离重启前资产；重启后重新准备授权，不为未知旧资产直接签发票据。

Radio 是同一媒体服务的 SERVER 消费者，执行 `radioInput` 能力门禁。它使用已验证的远程输入或准确版本的本地文件，不复制平台解析、全局降低 HTTPS 或按签名变化判断换曲。准备输入、正在运行的转码进程都绑定内容时间轴；未知重建播放对象拒绝输入。清空、暂停和切换时作废请求，迟到成功与空完成不遗留解析标记。首次临时断流刷新后立即重启，连续故障退避；停止时释放 pin 并恢复静音填充。

## 当前客户端与持久化

源标签、能力、分类、容器和源页面 URL 由后端目录与适配器驱动；图标和界面动作使用本地受控白名单，不执行服务器脚本或任意组件。浏览器媒体缓存的 CDN 白名单只用于安全优化，不参与音源发现。

客户端使用当前同步协议的完整快照、增量和丢包重同步，不订阅旧版本状态协议。切源、切目标和关闭弹窗时取消旧请求，重新进入时恢复未完成页面，不重复追加已提交内容。

本机存储和启动器配置只读写当前格式，不迁移旧来源或恢复旧模式别名。房间存档是例外：缺失或非当前 `schemaVersion` 的可解析存档先尝试保存 `.legacy-*.bak` 副本，导入可识别字段后按 `schemaVersion=1` 重写；读取失败则尝试保存 `.unreadable-*.bak` 副本，允许后续存档覆盖原路径。内置备份失败只记录警告，不阻止导入或后续写入，因此不能替代部署者备份。此行为包含未知版本，并非完整的版本化迁移框架。启动器使用 sources 映射，按启用配置启动网易 API 与 L-1124 原生 QQMusicApi Web 服务；QQ 内置模式随包提供隔离 Python，使用本次运行的回环地址，通过根状态与 OpenAPI 检查后再启动 Java，停止时清理自有进程树。QQ Web 不使用自写网关令牌，配置账号仅由 Java 按请求 Cookie 传递；内置默认账号池关闭且无账号种子。QQ 外部模式只连接独立 Web API，不接管其进程。Android 使用当前服务端页面与媒体桥，不增加平台专属播放器。

## 验证与边界

测试覆盖动态第三源、同ID跨源与多容器类型、公开目标隔离、空页游标、导入配额与竞态、两种交付、Range、授权轮换、内容版本变更、Radio 生命周期、FM/DJ 及本机数据行为。验证结果以 PR 最新提交说明为准。

仍需部署验证：真实账号与 CDN 权限、长时间 FFmpeg 播放、Windows 完整原生包及 Android 真机。媒体 URL 校验拒绝非公开地址及重定向，但 DNS 检查没有绑定实际传输连接；部署应限制出站网络。B站元数据较粗，不能承诺上游签名、风控或格式长期稳定。自动化与静态审查不能替代这些实测。
