### 进度条拖动（控制台可开关）

管理终端 → 播放核心区新增「允许拖动进度条」开关，**默认关闭**，关闭时进度条仅作展示。开启后：

- 房间成员的进度条可拖动（鼠标 / 触摸），松手后**房间内所有人同步跳转**
- 支持键盘：聚焦进度条后 `←` / `→` 微调 5 秒，按住 `Shift` 为 15 秒，`Home` / `End` 跳到首尾
- 位置由服务端裁剪到 `[0, 时长-500ms]`，拖到末尾不会误触「播完」
- **锁切歌、直播流开启时仍可拖动**：锁切歌只约束「换歌」；直播流本身跟随点播源，
  拖动会触发一次转码重启（拉流端可能有约一秒抖动）
- 游客不可操作，与其他播放控制一致

实现要点：`PlayerState.seekNonce` 在每次跳转时自增，客户端据此重锚房间时钟——否则「向后拖」
会被「迟到的状态包不能让时钟回退」的既有规则当成过期包忽略，拖动看起来毫无反应。
